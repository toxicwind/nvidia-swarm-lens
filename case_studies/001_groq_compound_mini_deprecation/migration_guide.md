## API Compatibility

### Groq API Format
```python
import groq
client = groq.Groq(api_key="...")
response = client.chat.completions.create(
    model="compound-mini",
    messages=[{"role": "user", "content": "Hello"}]
)
```

### NVIDIA NIM API Format
```python
import openai
client = openai.OpenAI(
    base_url="https://integrate.api.nvidia.com/v1",
    api_key="nvapi-..."
)
response = client.chat.completions.create(
    model="meta/llama-3.1-405b-instruct",
    messages=[{"role": "user", "content": "Hello"}]
)
```

## Key Differences

| Feature | Groq | NVIDIA NIM |
|---------|------|------------|
| Base URL | `api.groq.com` | `integrate.api.nvidia.com/v1` |
| Model ID | `compound-mini` | `meta/llama-3.1-405b-instruct` |
| Throughput | ~1000 tok/s (LPU) | ~3100 tok/s (H100) |
| Pricing | Per-token | Per-token |
| Streaming | Yes | Yes |
| Tool Calling | Limited | Grammar-constrained |
